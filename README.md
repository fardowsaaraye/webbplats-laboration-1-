## Svar på följande frågor om Git:
1. **Vad är skillnaden mellan git add och git commit?**
   Git add lägger till filer till staging area medans git commit kopierar alla filer från staging area till lokala repositoryt som en snapshot.
2. **Varför använder man branches istället för att jobba direkt i main?**
   Man använder branches för att kunna utveckla nya funktioner eller ändringar utan att påverka huvudversionen av projektet. När man är klar med ändringarna kan man slå ihop dem med main (merge).
3. **Vad händer rent praktiskt när man gör en merge?**
   När man gör en merge slår man samman den färdiga grenen med main.
4. **Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex Netlify?**
   Skillnaden är att Git push laddar upp filer från det lokala repot till ett remote repository, medan Netlify används för att publicera webbplatsen direkt på webben.
5. **Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?**
   Då använder jag en .gitignore fil i projektets rotmapp för att exkludera filer från versionshanteringen.
